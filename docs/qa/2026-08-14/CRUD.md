# GoKid — CRUD Matrix (static audit, 2026-08-14)

Reconciled against `src/db/schema.ts` (11 tables), every `src/app/api/*+api.ts` route, and the
screens under `src/app/**`. Read-only static analysis — no simulator, no dev server, no `curl`, no DB
query was run. "Verified" below means read directly in code; anything requiring a running system is
called out as NOT TESTABLE in the narrative report (`static-crud.md`).

Legend: **C/R/U/D** = does a code path exist. **Persisted** = does a write actually reach Postgres
(vs. only Clerk metadata / SecureStore / in-memory). **Validated** = runtime validation beyond
TypeScript types. **Authorised** = server-side check that the caller may act on this row.

## Classification legend used in the narrative report

- **SEED-GAP (unintended)** — the schema/architecture clearly intends this to work and it silently
  doesn't; nobody decided this on purpose.
- **SCOPE (intended, per PLAN.md)** — `PLAN.md` §"Out of scope for v1" explicitly excludes this
  (manual set/card/question authoring, e.g.).
- **DEMO-STANDIN (documented seam)** — a `lib/*` module says outright it is a stand-in for the API
  (`study.ts`, `rewards.ts`, `subscription.ts`) and screens are written against the seam, not the
  data, so swapping it is a lib-only change.
